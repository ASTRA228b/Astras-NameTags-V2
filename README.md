# Astra's NameTags V2

A simple nametag mod for Gorilla Tag.

It displays useful information above other players while keeping the UI clean and easy to read.

## Features

- Player name
- Player color
- FPS display
- FPS color indicator
- Speaker icon while talking
- Automatically adds and removes nametags
- Lightweight

## FPS Colors

- **72+ FPS** = Green
- **55-71 FPS** = Yellow
- **54 or lower** = Red

## Requirements

- Gorilla Tag PCVR
- BepInEx 5

## Installation

Put the DLL into:

```text
Gorilla Tag/BepInEx/plugins
```

Then launch Gorilla Tag.

## Notes 

The speaker icon only appears while the player is talking.
This mod is still being worked on, so things may change in future updates.
